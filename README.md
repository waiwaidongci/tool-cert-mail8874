# 工厂计量器具证书到期班报

交班前核对校准证书，逐台安排停用、送校与补档

澄岭精密零件厂 · 质量计量室 澄岭精密零件厂有机加工、装配和终检三处作业区，两班共用计量器具。过去由计量员把器具台账和校准机构的证书登记表逐项对照，再在交班群中通知线长。计量员现将两份清单合并导入，值班主管设定报告日、临期天数和覆盖门槛。班组在站内收件箱领取班报，按器具编号安排替换、送校和证书补档。

- 同一器具有多张历史证书，手工筛选时可能引用旧证或将后续签发的证书算入历史班报。
- 班组难以从单一到期总数判断哪台器具该停用、送校或补档。
- 证书登记缺口常在班报转发后才被发现。

## 业务模块

| 模块 | 用途 |
|---|---|
| 计量值班台 | 查阅业务口径、当班流程及最新运行。主管可以核对审计记录。 |
| 器具与证书 | 下载「澄岭厂器具台账及校准证书.csv」并核对字段。分析员可导入 UTF-8 CSV，保留数据指纹和原始行。 |
| 班报与定时计划 | 选择批次和参数并提交后台计算，可从运行列表追踪状态。 |
| 到期清单 | 查看业务指标、证据表和解释，通过来源链接回查数据。 |
| 班报复核 | 查看待处理或已完成记录。复核主管可提交班报处置及依据。 |
| 班报收件箱 | 查看计算报告、计划状态及站内投递和拦截回执，或下载 CSV。 |

## 启动

```bash
cp -n .env.example .env
docker compose config --quiet
docker compose up -d --build --wait
docker compose exec -T backend python -m scripts.seed_demo
```

## 演示流程

1. 11 月 21 日 07:30，计量员导入《澄岭厂器具台账及校准证书.csv》，其中有 6 台在用器具及 1 台停用器具。
2. 07:40，以 11 月 21 日为报告日生成班报，设置 14 天提醒和 80% 最低覆盖率。
3. 机加工卡尺 QC-101 已过期 1 天，线长换用有效备用卡尺并登记送校。
4. 装配扭矩扳手 QC-102 当日到期，线长在交班前安排换具和送校。
5. 计量员联系终检核对 QC-106 的证书，11 月 22 日签发的记录留待下一报告日采纳。
6. 主管确认 5/6 台有证书记录，配置站内定时分发。
7. 将覆盖门槛提高到 100% 试跑，班报保留逐台处置清单，定时分发暂停。

## 计算口径

- 在用范围取导入台账。每台器具选取签发日不晚于报告日的最新证书，同日按证书编号字典序取最后一条。
- 到期剩余天数 = 到期日减报告日。负值为已过期，0 为当日到期，其余在提醒天数内（含上限）为即将到期。
- 覆盖率 = 截至报告日有证书的在用器具数 ÷ 在用器具总数，已过期的证书也计入覆盖率。
- 至少有一台在用器具且实际覆盖率达到门槛时允许定时分发。每日计划推进报告日并读取最新导入批次。

## 本地开发

| 组件 | 实现 |
|---|---|
| 前端 | Nginx 与原生 HTML、CSS、JavaScript。`frontend/src/pages` 放页面，`components/common` 放共用表格、图表及表单。 |
| API | Python 3.11、FastAPI、SQLAlchemy。`backend/src/domain` 放本项目字段、业务计算和演示数据，`routes` 放接口，`models` 放表模型。 |
| 后台 | 独立 Python worker，通过 Redis 唤醒，从数据库租约领取计算，CSV 写入共享卷。 |
| 数据 | MySQL 8 存储批次、运行与审计。`backend/scripts/seed_demo.py` 可安全重复执行。 |

改动前端后执行 `docker compose up -d --build frontend`。改动接口或算法后执行 `docker compose up -d --build backend worker`，再刷新浏览器。如需保留数据，停止时执行 `docker compose down`。使用 `docker compose down -v --remove-orphans` 会清除该项目的数据库、Redis 和报表卷。

`.env.example` 中的 `COMPOSE_PROJECT_NAME`、`FRONTEND_PORT`、`BACKEND_PORT`、`DB_PORT`、`APP_SUBNET` 控制项目隔离。`DB_PASSWORD`、`JWT_SECRET` 和 `SEED_DEMO` 为本机演示默认设置。后端 `constants/enums.py` 与前端 `src/constants/enums.js` 保持角色、运行状态和复核状态一致。项目许可证见 `LICENSE`。
